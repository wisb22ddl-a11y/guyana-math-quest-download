## What the game is

A mathematics game for Grade 2, built around the Guyanese curriculum. Eighty
lessons across the ten regions of Guyana — counting through word problems — each
one its own game rather than a worksheet, and every question read aloud for
children who cannot yet read the words.

Once installed it needs **no internet at all**, which is why the installer is
large: every lesson and every recorded voice is inside it.

## Installing it

The file is not on the Play Store, so Android will warn you that it came from an
unknown source and ask whether to allow it. That warning is normal for any app
installed this way.

1. Download the `.apk` from the releases page above.
2. Open it. When Android asks, choose **Settings** → turn on **Allow from this
   source** → go back and tap **Install**.
3. Open **Guyana Math Quest** from your apps.

Needs Android 7 or newer, and about 1 GB of free space while it installs.

Every release here is signed with the same certificate,
`CN=Guyana Math Quest, C=GY`.
